# Chengxi She — Academic Homepage

Personal academic website: https://chengxishe.github.io/

Plain HTML, CSS and JavaScript. GitHub Pages publishes the `main` branch from the repository root. No build tools or dependencies are needed.

## Updating

- Edit `index.html` for profile, news, publications and contact information.
- Edit `style.css` for layout and appearance.
- `script.js` provides publication filtering; all content remains readable without JavaScript.
- Keep `.nojekyll` in the repository root.
- Update the date in the page footer when content changes.

Publication metadata was checked against Google Scholar and publisher records on October 10, 2026. The arXiv work is identified as a preprint; MAIPO is identified as online in 2026 with a 2027 journal issue. Current degree and education history are omitted until confirmed.
